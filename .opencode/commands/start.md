# /start — Find the next step

Understand the user's goal and name the best next command in one short sentence. Do not make the user learn the framework.

- Rough or new idea → `/brainstorm`
- Idea needs key product choices → `/interview`
- Clear idea needs a plan → `/plan`
- Wants something made or fixed → `/build`
- Wants the work checked → `/review`
- Wants to know what is next → `/status`

Ask one short question only if the goal is unclear.
