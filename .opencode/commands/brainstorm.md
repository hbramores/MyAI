# /brainstorm — Explore an idea

Nothing here is final. Help the user find a useful direction without making a full plan.

Reply in one or two short sentences. Give a few possible directions only when helpful. Do not ask normal system questions; work out the common system needs yourself.

Ask only about one meaningful product choice using the strict shared decision output contract, then stop. Do not give a long suggestion, a PRD, architecture, code, or preview of another question. When the idea is clear, ask if the user wants `/interview` or `/plan` in a separate reply.
